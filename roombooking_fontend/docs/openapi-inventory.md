## Backend and integration notes

- POST /api/auth/admin/register is intentionally conditional: SecurityConfig permits first-admin creation, while AuthService checks ADMIN authorization after an administrator already exists. OpenAPI advertises bearer auth; frontend may send a token when present and backend remains authoritative.
- Multipart properties are encoded with FormData. Repeated upload field is `files`; optional folder metadata uses `source` and repeated `relativePaths`.
- Search endpoints return PageResponse wrappers. Notifications return NotificationListResponse with a nested notifications page. Weekly schedule returns days, each containing bookings.
- Public room/avatar files and attachment download return binary data. Image URLs are built only from the backend public file endpoints or the URL value returned by the API.
- Spring Security matcher and method security enforce role checks; service methods enforce booking ownership. The frontend route guards are for navigation experience only.
